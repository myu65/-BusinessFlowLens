# 保留中の対応と、通常業務の再開を区別する

原文で結果の登録を保留していても、再調製や同じ確認への戻りまで止めてしまう候補が出た。解除を「依頼する」だけの矢印にも、通常業務を再開したと表示していた。依頼・例外対応と、実際の解除・再開を分けて扱う。

元の入力で同じ手順への戻りが明記され、前の手順を一つに特定できる場合は、保留中の対応としてその接続を残す。手順を重複させず、既存の手順へ戻すよう抽出時にも指示する。戻り先が複数ある、書かれていない、再実行を否定している場合はつながらない。接続候補を自動で補う処理ではない。

登録を保留する手順は、保留した結果の登録・更新を行ったことにしない。別の手順で明記された後の登録、異常の記録、試料を実際に再調製することは保持する。人が訂正した情報は元の根拠とともに残す。
