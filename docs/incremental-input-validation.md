## 変更した体験

矢印の＋から、間にある作業を一文で追加できる。右に「前の手順→ここに追加→次の手順」を示し、分岐のある場合は追加する枝を選ぶ。追加した話だけをAIで読み取り、元の手順、他の枝、人の訂正を保つ。追加は保存前の候補に反映し、手順を選んで担当・道具・情報を確認、訂正してから保存する。

書きかけの文章と、選んだ矢印をブラウザのセッションに残す。まだ反映していない追記があるときは、そのまま保存できない。変更を加えていない直前の追加は取り消せる。元の本文は書き換えず、追加した一文を末尾に残す。追加位置は人が指定した関係として、原文の内容とは別に記録する。

図は6手順までを表示する。確認できた結果をカードの見出しに使い、推定の結果は確定したように表示しない。担当は別に示し、担当を訂正した後に見出しが以前の担当を述べないようにした。元の手順名と原文は保持する。人の訂正、推定の矢印、前後が未知の手順も区別する。
