# 図の横で次の手順と戻り先を直す

AIが戻り先を読み落とした場合でも、長い詳細フォームを探さず直せるようにした。図で手順を選び「矢印を直す」から、次の手順・条件・進み方を選ぶ。保留中の再調製・解除依頼と、実際の保留解除・通常業務の再開を分けて記録する。業務内の接続が対象で、別業務への受渡しは従来の受渡し編集から行う。

変更は保存前の図と差分に反映する。追加・変更・除外を取り消せる。除外した矢印と元の根拠は別に保持し、AIによる再整理で復活させない。条件の表現だけが変わった接続の再提案も、人が確認するまで採用しない。既存の別条件の経路は保持する。
